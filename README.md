# Device Lifecycle Tracker

A self-built asset management case study tracking one fictional laptop through its complete lifecycle, demonstrating IT asset management fundamentals.

## Objective

Show a structured, documented approach to device lifecycle management, from initial procurement through configuration, assignment, ongoing maintenance, and eventual retirement or reassignment.

## Lifecycle Documentation

See [laptop-lifecycle.md](laptop-lifecycle.md) for the full asset record and lifecycle breakdown.

## Notes

This is a solo-built simulation lab. All asset details, users, and scenarios are fictional.
